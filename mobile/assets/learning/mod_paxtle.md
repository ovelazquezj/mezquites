# Reconocer el paxtle (heno motita)

El paxtle (*Tillandsia recurvata*) es una epífita gris en "motas": no chupa savia, pero compite por luz y pesa sobre las ramas. *(Stub de dev — el contenido real lo provee `docs/learning/`.)*
